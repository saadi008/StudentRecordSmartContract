## 📖 Project Overview

The **Student Record Management Smart Contract** is a blockchain-based application developed using **Solidity** and **Remix Desktop IDE**.

The contract securely stores student records on the Ethereum blockchain while ensuring that only the contract owner can create, update, or delete records.

This project was developed as a university Blockchain assignment and is also maintained as a portfolio project.

---

## ✨ Features

- ✅ Add Student
- ✅ Get Student Details
- ✅ Update Student Record
- ✅ Delete Student Record
- ✅ Count Total Students
- ✅ Owner Access Control
- ✅ Blockchain Events
- ✅ Decentralized Data Storage

## 🚀 How to Run

1. Install Remix Desktop IDE.
2. Create a Solidity file named `StudentRecord.sol`.
3. Paste the smart contract code.
4. Compile using Solidity 0.8.x.
5. Deploy using Remix VM (Cancun).
6. Test all contract functions.
